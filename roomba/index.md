# Roomba Modifications

Explore robot movement and sensor integration by modifying Roomba robots. This unit introduces fundamental robotics concepts through hands-on work with real robot platforms.

## Learning Objectives

By the end of this unit, you will be able to:
- Control robot movement and navigation
- Integrate sensors for environmental awareness  
- Program autonomous behaviors
- Understand robot-environment interaction
