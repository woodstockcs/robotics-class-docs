# Electronics Basics

Learn the fundamental concepts of electronics that power all robots. This unit covers the essential components, circuits, and techniques you'll use throughout the course.

## Learning Objectives

By the end of this unit, you will be able to:
- Build basic circuits on breadboards
- Connect and control LEDs, sensors, and displays
- Understand voltage, current, and resistance
- Troubleshoot common circuit problems

## Support Resources

### Troubleshooting
- [Ben Eater Breadboard Tips](https://www.youtube.com/watch?v=PE-_rJqvDhQ) - Professional techniques
- [Wire Cutting and Preparation](https://www.youtube.com/watch?v=ver-Av8vr1Q) - Clean connections

### Common Issues
- **No power**: Check power connections and voltage
- **Component not working**: Verify wiring and component orientation  
- **Intermittent problems**: Look for loose connections
- **Short circuits**: Check for crossed wires
