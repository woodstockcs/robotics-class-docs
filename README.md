# Robotics at Woodstock

This is the course documentation site for robotics classes at Woodstock Union High School Middle School.

## 🚀 Quick Start

- **Students**: Start with the [Getting Started Guide](https://woodstockcs.github.io/robotics-class-docs/getting-started)
- **Course Overview**: Visit the [main site](https://woodstockcs.github.io/robotics-class-docs/)
- **Need Help?**: Check the [Troubleshooting Guide](https://woodstockcs.github.io/robotics-class-docs/troubleshooting)

## 📚 Course Structure

The course follows a progressive learning path:

1. **Fundamentals** - Electronics and programming basics
2. **Introductory Projects** - LEDs and robot movement
3. **Challenge Projects** - Freeze tag and sumo wrestling competitions
4. **Advanced Topics** - Mechanical systems and gears
5. **Enrichment** - Algorithm challenges and problem-solving

## 🛠 Development

This site is built with Jekyll using the just-the-docs theme and deploys automatically via GitHub Pages.
